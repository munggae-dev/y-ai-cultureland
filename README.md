# Y-AI 컬쳐랜드 사용처 안내

Y-AI 메이커톤을 위한 컬쳐랜드 모바일 PWA 시제품입니다. 온라인·오프라인 사용처 검색, 매장별 사용 안내, 영등포역 주변 매장 지도와 도보 경로를 제공합니다.

## 로컬 실행

```sh
npm run dev
```

기본 주소는 `http://127.0.0.1:4173/`입니다. `npm run check`로 JavaScript 문법과 데이터·경로 테스트를 실행합니다. 별도 빌드 단계는 없습니다.

## 데이터 범위

매장 목록과 도보 경로는 영등포역 주변에 한정됩니다. 길안내 경로는 영등포역 출구에서 시작하며, 위치 권한을 허용하면 지도에 현재 위치와 경로 진행 상황을 표시합니다. 현재 위치에서 새 경로를 계산하지는 않습니다. 출처와 갱신 방법은 [DATA_SOURCES.md](DATA_SOURCES.md)에 정리했습니다.
